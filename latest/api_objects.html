API object index

API object index#

The stub page of every documented object. The API pages carry the same object lists as tables, each entry linking the stub this page writes; writing them here keeps them out of the toctree the sidebar is built from.

SequencePlugin

A sequence function bound to the entries of the scanner protocol.

Evaluation

The outcome of SequencePlugin.evaluate() for a valid protocol.

Protocol

The values of a plugin's protocol, in the units of the sequence function's arguments.

ScannerSequence

Deprecated name of SequencePlugin.

load_plugin

Import a plugin file and instantiate the one SequencePlugin it defines.

load_exam

Return the cache of the exam whose directory a design hook was given.

RfLayout

The RF definitions a plugin plays and the instances of one TR.

RfControl

TimeParam

A time UI entry bound to an argument of the sequence function, in seconds.

FloatParam

A float UI entry bound to an argument of the sequence function.

IntParam

An integer UI entry bound to an argument of the sequence function; a dropdown when it has options.

BoolParam

A checkbox UI entry bound to an argument of the sequence function.

ChoiceParam

A choice among the members of a StrEnum, bound to an argument of the sequence function.

StringListParam

Return a ChoiceParam over a StrEnum built from option strings.

ConfigParam

A value the sequence declares to the interpreter; never shown or edited.

Description

A read-only text row in the UI.

call

Answer one design call: exit status 0 and its reply, or 1 and an ERROR line.

DesignStore

The designs under one directory, each in <id>/ and immutable once written.

design_identity

Return the SHA-256, in hexadecimal, of everything a design depends on.

design_id

Return the identifier of a design: the first ID_DIGITS digits of its identity.

convert

Segment a sequence file and write its IR cache beside it.

prescribe

Move a logical-frame sequence to a prescribed field-of-view centre, in place.

check

Return the problems of a chain under a scanner's limits, in the physical frame.

CheckLimits

The nerve and resonance limits of a chain, and the VOPs of its SAR ratios, besides pypulseqpp.Opts.

sar_ratios

Return the SAR ratios of each file of a chain against the reference pulse.

SarRatio

A subsequence's RF energy at the VOPs, against the reference pulse.

played_rf

Return the definition and designed angle of each RF row a sequence plays.

summary

Return the segmentation of a sequence: subsequences, segments and readouts.

play

Walk the cache beside a sequence file as the scanner's playout does.

plan_waves

Lay out the waves of the cache beside a sequence file in a playout's waveform memory.

WaveBudget

What a playout's waveform memory affords the waves.

Grouping

Rule by which the blocks of a repetition are grouped into virtual segments.

VendorProfile

What a cache holds its numbers as, for the machine that reads it.

read_vendor

Read a vendor file into the profile and grouping a conversion takes.

Quantity

The format one quantity is stored in, and what one integer step means.

sample_wave

Return a wave as a playout loads it into a region, normalised to unit peak.

playout

Play the cache beside a sequence file as a segmented playout plays it, recording both stages.

Prescan

The receive-gain calibration a playout plays instead of the scan.

repetition_gradients

Return the gradients of a subsequence's repetition of most gradient energy.

chain

Return the files of the NextSequence chain starting at a sequence file, in play order.

cache_path

Return the cache file of a sequence: its last suffix replaced by cache_ext.

Format

What a quantity is stored as.

has_acquisition_flag

Return whether an acquisition carries one flag.

acquisition_label

Return one acquisition label by MRD field name.

acquisition_labels

Return encoding_space_ref and the MRD index counters; absent ones are None.

AcquisitionBucket

Acquisitions accumulated up to a boundary, split as Gadgetron splits them.

AcquisitionBucketStats

Distinct values of each encoding counter in one bucket.

MrdMetadata

Accessors over one parsed MRD XML header.

EncodingSpace

Buffer layout of one encoding space of an MRD header.

LOOP_COUNTERS

Built-in immutable sequence.

user_parameter

Return an MRD header user parameter by name, or default when absent.

max_stored_value

Return the largest pixel value of BitsStored bits, 12 bits when unstated.

coil_combine

Combine the coil axis of a stack of coil images.

center_crop

Crop the trailing axes of an image to a centred window.

as_numpy

Return an array as NumPy on the host; Torch tensors are detached first.

read_chain

Read a sequence file and every file its NextSequence definitions name, in play order.

SequenceDefinitions

Definitions describing what a sequence acquires, in Pulseq units.

ReadoutTable

Every ADC readout of one sequence, in play order.

AcquisitionFlag

ISMRMRD acquisition flags as bit masks, combinable with |.

Parameter

One protocol entry: its kind, current value and UI schema.

ProtocolKey

Represent a PEP 604 union type

UIParam

The keys of the scanner UI's controls, from every typed group.

PRESCRIPTION

Built-in immutable sequence.

FOV_OFFSET

Built-in immutable sequence.

FOV_ROTATION

Built-in immutable sequence.

prescribed_offset

Return the field-of-view offset protocol values carry, in metres.

prescribed_rotation

Return the (3, 3) rotation from logical to physical axes protocol values carry.

PROTOCOL_BEGIN

str(object='') -> str str(bytes_or_buffer[, encoding[, errors]]) -> str

PROTOCOL_END

str(object='') -> str str(bytes_or_buffer[, encoding[, errors]]) -> str

format_listing

Format a protocol with its schema, as the list design call replies it.

parse_listing

Read a protocol with its schema from a listing block.

format_values

Format a value block, as requests and replies carry it.

parse_values

Read a value block against the listing it was edited from.

format_prescription

Format prescription entries as the name: value lines of a block.

parse_prescription

Read the prescription entries out of the name: value lines of a block.

Validation

Reply of the validate design call.

format_validation

Format a validate reply: status line, info line, value block.

parse_validation

Read a validate reply.

RfDefinitionRecord

One RF definition of an [RfDefinitions] block.

format_rf_definitions

Format the RF definitions of an evaluation, as the list design call replies them.

parse_rf_definitions

Read the [RfDefinitions] block of a list reply.

RfLayoutRecord

The contents of an [RfLayout] block, one entry per instance of one TR in play order.

format_rf_layout

Format the RF layout of a validation, as the validate design call replies it.

parse_rf_layout

Read the [RfLayout] block of a validate reply.

Kind

Type tag of a protocol entry on the wire.

InputMode

How a numeric entry is presented in the scanner UI.

TEPreset

Echo-time dropdown entries the UI shows as words.

TRPreset

Repetition-time dropdown entries the UI shows as words.

FloatKey

Keys the interpreter declares as float.

IntKey

Keys the interpreter declares as integer.

BoolKey

Keys the interpreter declares as boolean.

EnumKey

Keys the interpreter declares as string lists.

ConfigKey

Keys the sequence declares to the interpreter rather than shows.

UserKey

Keys of the float user entries, user0_value to user18_value.

UserNameKey

Keys of the descriptions naming the user entries, user0_name to user18_name.

SequenceType

Options of sequence_type.

ImagingMode

Options of imaging_mode.

PreparationType

Options of preparation_type.

TriggerType

Options of trigger_type.

ReconProxy

Routes each series of an MRD stream to a reconstruction.

ReconServer

Reconstructs each series of an MRD stream as it is received.

LocalReconstruction

Reconstructs series in this process, one at a time, as ReconProxy's workers do.

DesignCache

The designs of a store, the most recently read kept tabulated.

Design

A stored design, as the reconstruction side reads it.

DESIGN_PARAMETER

str(object='') -> str str(bytes_or_buffer[, encoding[, errors]]) -> str

DesignIntake

Receives stored designs over HTTP into the design store the proxy reads.

SequenceTable

The readouts of a sequence chain as MRD describes them, in play order.

TableSpace

One encoding space of a SequenceTable.

enrich_header

Describe the table's encoding spaces and sequence parameters in an MRD header.

enrich_acquisition

Stamp row index of the table on one acquisition, in place.

ReconPlugin

Base class for reconstruction plugins.

Gadget

One per-acquisition step of a plugin's gadgets.

load_plugin

Import a plugin file and return the PLUGIN instance it defines.

AsymmetricEcho

Zero-fill a partial echo to the full echo that is symmetric about its center_sample.

Prewhiten

Whiten the channels of each readout with the stream's noise measurement.

RemoveReadoutOversampling

Crop each readout to the readout field of view of the reconstruction.

ReconContext

Scan context passed to every hook of a plugin.

ExamCache

Thread-safe store of artifacts shared by the series of one exam.

ExamImage

An image measured by one series and read by later series of the exam.

B0_MAP

str(object='') -> str str(bytes_or_buffer[, encoding[, errors]]) -> str

B1_MAP

str(object='') -> str str(bytes_or_buffer[, encoding[, errors]]) -> str

COIL_SENSITIVITIES

str(object='') -> str str(bytes_or_buffer[, encoding[, errors]]) -> str

NOISE_COVARIANCE

str(object='') -> str str(bytes_or_buffer[, encoding[, errors]]) -> str

EXAM_ARTIFACTS

Built-in immutable sequence.

coil_maps

Return the coil sensitivities of a unit from the first source that has them.

CoilSensitivities

Receive coil sensitivity maps, with what they were estimated from.

MissingCalibration

No source holds a calibration the stream can use.

CoilCompression

Reduce the receive channels of a unit's k-space to virtual channels.

gradient_unwarped

Return an image resampled from where its voxels were acquired to where they belong.

ReconData

The readouts of one reconstruction unit, as ReconPlugin.recon() receives them.

ReconBuffer

K-space of one encoding space, filled one acquisition at a time.

ReconResult

Image array for the runtime to package as an MRD image, or as DICOM.

validate

Check that a sequence plays as it was written.

Comparison

What a comparison established, and what it compared against.

ChannelAgreement

How far apart one channel's two renderings are.

gradient_tolerance_mt_per_m

Return how far two renderings of a gradient may differ and still agree.

read_waveform_xml

Read one waveform XML file.

PlayedWaveforms

What a scanner played, as its plotter recorded it.

VENDORS

Built-in immutable sequence.

trajectory

Return the k-space location of every ADC sample the cache beside a sequence file plays.

acquire

Return the samples the cache beside a sequence file acquires of a phantom.

simulate

Return what each coil receives at every ADC sample the cache beside a sequence file plays on isochromats.

excited

Return the slabs the excitation pulses of the cache beside a sequence file excite; None where one excites every isochromat.

Slabs

Slabs of the physical frame, each the isochromats that see a field within its bounds during a pulse.

Isochromats

Isochromats, and the magnetisation the Bloch equation carries from one block to the next.

Repetitions

Repetitions of a sequence of blocks, played in turn on isochromats.

RigidMotion

A subject moving as a rigid body, as Isochromats takes a motion.

Scan

The cache beside a sequence file played on isochromats, against a scan clock.

Chunk

A span of a virtual scan between two block boundaries.

SAMPLE_RATE

Convert a string or number to a floating-point number, if possible.

export

Write the blocks the cache beside a sequence file plays as one Pulseq 1.5.1 file.

Phantom

Ellipses whose signals add, received by one coil or several.

BrainWeb

BrainWeb's normal brain, received by one coil or several.

Ellipse

An ellipse of uniform magnetization in a plane of constant z.

localizer

Return the axial, coronal and sagittal images of a phantom's proton density, as DICOM.

Coil

The RF coils of an exam, fixed in the physical frame: the coil pulses are transmitted on and the coil the signal is received by.

COILS

the body coil both ways, the body coil transmitting to a 48-channel receive head array, and an 8-channel head coil for parallel transmission with a 32-channel receive head array.

send

Send one series to the proxy at address; return what it sends back.

record

Write one series to an ISMRMRD file as send() sends it; return the readouts written.

Console

What a scanner console asks of pulserver, answered in this process.
