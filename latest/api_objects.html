API object index

API object index#

The stub page of every documented object. The API pages carry the same object lists as tables, each entry linking the stub this page writes; writing them here keeps them out of the toctree the sidebar is built from.

ScannerSequence

A pypulseqpp application exposed to the scanner UI.

load_plugin

Import a plugin file and instantiate the one ScannerSequence it defines.

TimeParam

A time UI entry bound to an init_sequence argument in seconds.

FloatParam

A float UI entry bound to an init_sequence argument.

IntParam

An integer UI entry bound to an init_sequence argument; a dropdown when it has options.

BoolParam

A checkbox UI entry bound to an init_sequence argument.

StringListParam

A choice among option strings, bound to an init_sequence argument.

ConfigParam

A value the sequence declares to the interpreter; never shown or edited.

Description

A read-only text row in the UI.

HostDaemon

Design sessions for every PSD host process on this host.

HostClient

One session's connection to the host daemon.

HostError

The daemon answered a command with ERROR.

SessionKey

A host PSD process: its PID and the day it started.

SessionStore

All sessions under <base>/bucket, loaded from disk on first use.

Session

One session's state, persisted in bucket/<key>/.

revision_hash

Identify a design by plugin, scanner limits, resolved protocol and source.

convert

Segment a sequence file and write its IR cache beside it.

prescribe

Move a logical-frame sequence to a prescribed field-of-view centre, in place.

check

Return the timing and gradient problems of a chain under a scanner's limits.

summary

Return the segmentation of a sequence: subsequences, segments and readouts.

play

Walk the cache beside a sequence file as the scanner's playout does.

chain

Return the files of the NextSequence chain starting at a sequence file, in play order.

cache_path

Return the cache file of a sequence: its last suffix replaced by cache_ext.

has_acquisition_flag

Return whether an acquisition carries one flag.

acquisition_label

Return one acquisition label by MRD field name.

acquisition_labels

Return encoding_space_ref and the MRD index counters; absent ones are None.

AcquisitionBucket

Acquisitions accumulated up to a boundary, split as Gadgetron splits them.

AcquisitionBucketStats

Distinct values of each encoding counter in one bucket.

MrdMetadata

Accessors over one parsed MRD XML header.

EncodingSpace

Buffer layout of one encoding space of an MRD header.

LOOP_COUNTERS

Built-in immutable sequence.

user_parameter

Return an MRD header user parameter by name, or default when absent.

max_stored_value

Return the largest pixel value of BitsStored bits, 12 bits when unstated.

coil_combine

Combine the coil axis of a stack of coil images.

center_crop

Crop the trailing axes of an image to a centred window.

as_numpy

Return an array as NumPy on the host; Torch tensors are detached first.

read_chain

Read a sequence file and every file its NextSequence definitions name, in play order.

SequenceDefinitions

Definitions describing what a sequence acquires, in Pulseq units.

ReadoutTable

Every ADC readout of one sequence, in play order.

AcquisitionFlag

ISMRMRD acquisition flags as bit masks, combinable with |.

Parameter

One protocol entry: its kind, current value and UI schema.

UIParam

The keys of the scanner UI's controls, from every typed group.

PRESCRIPTION

Built-in immutable sequence.

prescribed_offset

Return the field-of-view offset protocol values carry, in metres.

PROTOCOL_BEGIN

str(object='') -> str str(bytes_or_buffer[, encoding[, errors]]) -> str

PROTOCOL_END

str(object='') -> str str(bytes_or_buffer[, encoding[, errors]]) -> str

format_listing

Format a protocol with its schema, as LIST_PROTOCOL sends it.

parse_listing

Read a protocol with its schema from a listing block.

format_values

Format a value block, as requests and replies carry it.

parse_values

Read a value block against the listing it was edited from.

Validation

Reply to VALIDATE.

format_validation

Format a VALIDATE reply: status line, info line, value block.

parse_validation

Read a VALIDATE reply.

Kind

Type tag of a protocol entry on the wire.

InputMode

How a numeric entry is presented in the scanner UI.

TEPreset

Echo-time dropdown entries the UI shows as words.

TRPreset

Repetition-time dropdown entries the UI shows as words.

FloatKey

Keys the interpreter declares as float.

IntKey

Keys the interpreter declares as integer.

BoolKey

Keys the interpreter declares as boolean.

EnumKey

Keys the interpreter declares as string lists.

ConfigKey

Keys the sequence declares to the interpreter rather than shows.

SequenceType

Options of sequence_type.

ImagingMode

Options of imaging_mode.

PreparationType

Options of preparation_type.

TriggerType

Options of trigger_type.

ReconPlugin

Base class for reconstruction plugins.

Gadget

One per-acquisition step of a plugin's chain.

load_plugin

Import a plugin file and return the PLUGIN instance it defines.

ReconContext

Scan context passed to every hook of a plugin.

ExamCache

Thread-safe store of artifacts shared by the series of one exam.

ReconData

Every encoding space of a scan, mapping space index to ReconBuffer.

ReconBuffer

K-space of one encoding space, filled one acquisition at a time.

ReconResult

Image array for the runtime to package as an MRD image.

ReconProxy

Routes each series of an MRD stream to a reconstruction worker.

RevisionStore

The revisions under <base>/bucket, the most recently read kept.

Revision

A generated design, as the reconstruction side reads it.

SESSION_PARAMETER

str(object='') -> str str(bytes_or_buffer[, encoding[, errors]]) -> str

REVISION_PARAMETER

str(object='') -> str str(bytes_or_buffer[, encoding[, errors]]) -> str

SequenceTable

The readouts of a sequence chain as MRD describes them, in play order.

TableSpace

One encoding space of a SequenceTable.

enrich_header

Describe the table's encoding spaces and sequence parameters in an MRD header.

enrich_acquisition

Stamp row index of the table on one acquisition, in place.
